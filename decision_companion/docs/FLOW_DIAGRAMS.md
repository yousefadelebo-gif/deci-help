## 4. AI Analysis Flow

```
┌─────────────────────────────────────────────────────────────────────────────────────────────┐
│                                    AI ANALYSIS FLOW                                          │
└─────────────────────────────────────────────────────────────────────────────────────────────┘

    ┌────────┐        ┌──────────┐        ┌───────────┐        ┌──────────┐
    │ Client │        │  Views   │        │ AIService │        │ Database │
    └───┬────┘        └────┬─────┘        └─────┬─────┘        └────┬─────┘
        │                  │                    │                   │
        │ POST /decisions/ │                    │                   │
        │ {id}/ai/analyze  │                    │                   │
        │─────────────────►│                    │                   │
        │                  │                    │                   │
        │                  │ Get decision       │                   │
        │                  │────────────────────────────────────────►
        │                  │◄────────────────────────────────────────
        │                  │                    │                   │
        │                  │ Validate:          │                   │
        │                  │ - Has options?     │                   │
        │                  │ - Has factors?     │                   │
        │                  │                    │                   │
        │                  │ Initialize service │                   │
        │                  │───────────────────►│                   │
        │                  │                    │                   │
        │                  │ Call analyze()     │                   │
        │                  │───────────────────►│                   │
        │                  │                    │                   │
        │                  │                    │ Get options       │
        │                  │                    │──────────────────►│
        │                  │                    │◄──────────────────│
        │                  │                    │                   │
        │                  │                    │ Get factors       │
        │                  │                    │──────────────────►│
        │                  │                    │◄──────────────────│
        │                  │                    │                   │
        │                  │                    │ Get factor scores │
        │                  │                    │──────────────────►│
        │                  │                    │◄──────────────────│
        │                  │                    │                   │


    ┌─────────────────────────────────────────────────────────────────────────────────────┐
    │                         AI SCORING ALGORITHM                                         │
    ├─────────────────────────────────────────────────────────────────────────────────────┤
    │                                                                                     │
    │  FOR EACH OPTION:                                                                   │
    │  ┌─────────────────────────────────────────────────────────────────────────────┐   │
    │  │                                                                             │   │
    │  │  weighted_score = 0                                                         │   │
    │  │                                                                             │   │
    │  │  FOR EACH FACTOR:                                                           │   │
    │  │  ┌─────────────────────────────────────────────────────────────────────┐   │   │
    │  │  │                                                                     │   │   │
    │  │  │  score = factor_score[factor, option] or 5 (default)               │   │   │
    │  │  │  weighted_value = score × factor.weight                             │   │   │
    │  │  │                                                                     │   │   │
    │  │  │  IF factor.category == 'PRO':                                       │   │   │
    │  │  │      weighted_score += weighted_value                               │   │   │
    │  │  │  ELSE IF factor.category == 'CON':                                  │   │   │
    │  │  │      weighted_score -= weighted_value                               │   │   │
    │  │  │                                                                     │   │   │
    │  │  └─────────────────────────────────────────────────────────────────────┘   │   │
    │  │                                                                             │   │
    │  └─────────────────────────────────────────────────────────────────────────────┘   │
    │                                                                                     │
    │  NORMALIZE SCORES:                                                                  │
    │  ┌─────────────────────────────────────────────────────────────────────────────┐   │
    │  │                                                                             │   │
    │  │  min_score = MIN(all_raw_scores)                                            │   │
    │  │  max_score = MAX(all_raw_scores)                                            │   │
    │  │  range = max_score - min_score                                              │   │
    │  │                                                                             │   │
    │  │  FOR EACH OPTION:                                                           │   │
    │  │      normalized_score = ((raw_score - min_score) / range) × 100            │   │
    │  │                                                                             │   │
    │  └─────────────────────────────────────────────────────────────────────────────┘   │
    │                                                                                     │
    │  CALCULATE CONFIDENCE:                                                              │
    │  ┌─────────────────────────────────────────────────────────────────────────────┐   │
    │  │                                                                             │   │
    │  │  variance = Σ(score - avg_score)² / n                                       │   │
    │  │  score_confidence = MIN(100, variance × 2)                                  │   │
    │  │  completeness = (actual_scores / total_needed) × 100                        │   │
    │  │                                                                             │   │
    │  │  confidence = (score_confidence × 0.6) + (completeness × 0.4)              │   │
    │  │  confidence = CLAMP(confidence, 30, 95)                                     │   │
    │  │                                                                             │   │
    │  └─────────────────────────────────────────────────────────────────────────────┘   │
    │                                                                                     │
    └─────────────────────────────────────────────────────────────────────────────────────┘


        │                  │                    │                   │
        │                  │                    │ Save Result       │
        │                  │                    │──────────────────►│
        │                  │                    │◄──────────────────│
        │                  │                    │                   │
        │                  │                    │ Update Decision   │
        │                  │                    │ status=ANALYZED   │
        │                  │                    │──────────────────►│
        │                  │                    │◄──────────────────│
        │                  │                    │                   │
        │                  │◄───────────────────│                   │
        │                  │ Return result      │                   │
        │                  │                    │                   │
        │                  │ Log activity       │                   │
        │                  │────────────────────────────────────────►
        │◄─────────────────│                    │                   │
        │ {decision_id,    │                    │                   │
        │  recommended,    │                    │                   │
        │  confidence,     │                    │                   │
        │  explanation,    │                    │                   │
        │  breakdown}      │                    │                   │
        │                  │                    │                   │
```
